# AzsaPlayer

[English](README.md)

[MusicBee](https://getmusicbee.com/) と同じようにタグを解釈する（複数アーティスト・ソートタグ・リプレイゲイン）、Android 用の音楽ライブラリプレーヤーです。
デジタルオーディオプレーヤー HiBy R4（Android 12）向けに作りましたが、Android 12 以降の端末で動きます。

「初期状態は極端に簡素、設定によって細かく作り込める」ことを設計方針にしています。

## 主な機能

- **MusicBee と同じ複数アーティストの扱い** — 本物の複数値（ID3v2 の NULL 区切り、Vorbis Comment の同名フィールド、MP4 の同名アトムの繰り返し）と `;` 区切りの値を、別々のアーティストとして扱います。`AC/DC` や `Earth, Wind & Fire` は分割しません。
- **ソートタグ** — `ARTISTSORT`・`ALBUMARTISTSORT`・`ALBUMSORT`・`TITLESORT`・`COMPOSERSORT` で並べ、表示はタグどおりの名前のままです。並び替えは ICU の照合順（英字 → かな → 漢字。Windows 版 MusicBee と同じ順）です。
- **リプレイゲイン** — トラック／アルバム／自動、プリアンプ、クリッピング防止。アプリ内のデジタル処理で、ギャップレス再生でも曲の境目でサンプル単位で正確に切り替えます。端末の音量機構やエフェクトは使いません。
- **音質** — 32ビット浮動小数点でデコードし、そのまま浮動小数点で出力します。加える処理はリプレイゲインだけです。AAC デコーダの DRC・ラウドネス正規化は無効にしています。
- **ギャップレス再生**、キューの編集、曲単位・アルバム単位のシャッフル、リピート、終了後の再生位置の復元。
- **ホームのカスタマイズ** — タブの選択と並べ替え（アルバムアーティスト・アーティスト・アルバム・曲・作曲者・ジャンル・年・年代・フォルダ・プレイリスト・最近追加した曲・Album Flow・任意のタグ）、曲に至るまでの階層、リスト／グリッド、アートワーク、`<Artist> — <Year>` のような2行のテンプレート。
- ジャケットを見ながらアルバムを選べる、仮想スクロールホイール付きの **Album Flow**。
- ひらがな／カタカナ・全角／半角・大文字／小文字を区別せず、ソートタグの読みでも見つかる**検索**。
- プレイリスト、M3U/M3U8 の読み込み（MusicBee から書き出したプレイリストの Windows パスを置き換えられます）。
- 日本語・英語に対応。

## 対応形式

ライブラリ：FLAC・MP3・M4A（AAC/ALAC）・Ogg Vorbis・Opus・WAV・AIFF・APE・WavPack・DSF/DFF・Musepack（タグは TagLib で読み取ります）。
再生：Android 標準のデコーダで再生できる形式（FLAC・MP3・AAC・Vorbis・Opus・WAV、対応端末では ALAC）。それ以外は一覧に表示し「再生不可」と示します。

## インストール

1. [Releases](../../releases) から最新の `AzsaPlayer-x.y.z.apk` をダウンロードします。
2. 端末で開き、確認が出たらこの提供元からのインストールを許可します。
3. 初回起動時に、許可する範囲を選びます。
   - **音楽ファイルの読み取りのみ（おすすめ）** — 一般的な音声ファイルとジャケット画像を読み取ります。Android が音声として扱わない形式（APE・DSD・WavPack など）や M3U ファイルは表示されないことがあります。
   - **すべてのファイルへのアクセス** — すべての形式を読み取れます。あとから「設定 > ライブラリ」で変更できます。
4. 「設定 > ライブラリ」で音楽フォルダを追加し、「スキャン」を押します。

音楽ファイルへの書き込みや削除は一切行いません。インターネット権限はなく、データも収集しません。

### MusicBee をお使いの方へ

- MusicBee のタグ編集画面で**灰色**で表示されるソート値は、MusicBee 独自のカスタムソート値で、ファイルには書き込まれていません。「ソート」欄に値を入力して保存すると、ファイルに書き込まれます（`ARTISTSORT` など）。
- プレイリストは MusicBee から M3U で書き出し、`D:\Music\` → `/storage/XXXX-XXXX/Music/` のようなパスの置き換え規則を追加してください。

## ソースからのビルド

必要なもの：Android Studio（同梱の JDK 17 以上）、Android SDK 37、NDK 30.0.16248370、CMake 4.1.2。

```bash
./gradlew assembleDebug
```

テスト：

```bash
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest
```

仕様書は [SPEC.md](SPEC.md) にあります。
